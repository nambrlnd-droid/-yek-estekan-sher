# نسخهٔ ۱.۸ — مرحلهٔ پنجم: صفحه‌های مستقل شعر و شاعر

## صفحهٔ مستقل هر شعر
- مسیر پایدار و قابل پیوند `#/read/<id>` با شناسهٔ اصلی اثر.
- نمایش عنوان، متن بدون بازنویسی، نام شاعر، برچسب‌ها و سه سطح موضوعی.
- شناسنامهٔ عروضی شامل نوع ساختار، تعداد مصراع، برآورد هجای نوشتاری و وضعیت قافیه/ردیف؛ وزن و بحر در صورت نبود تأیید، صریحاً «تأیید نشده» نمایش داده می‌شوند.
- آثار هم‌موضوع و مشابه با تکیه بر اشتراک طبقه‌بندی سلسله‌مراتبی و واژگان.
- کپی متن، اشتراک‌گذاری پیوند، نشان‌کردن، یادداشت شخصی و افزودن به مجموعه حفظ شده‌اند.
- پیوند مستقیم برای گزارش اشکال یا اصلاح اطلاعات از طریق GitHub Issues.

## صفحهٔ مستقل هر شاعر
- مسیر قابل پیوند `#/poet/<author>` بر اساس نام ثبت‌شدهٔ شاعر.
- نمایش تعداد آثار و گسترهٔ موضوعی.
- فهرست آثار همان شاعر با عنوان، گزیدهٔ متن و موضوعات.
- صفحه‌بندی ۵۰تایی برای جلوگیری از رندر سنگین روی موبایل.
- بازکردن هر اثر از صفحهٔ شاعر به صفحهٔ مطالعهٔ مستقل آن.

## ملاحظات داده
- نام شاعر و متن اثر دست‌کاری نمی‌شوند؛ تطبیق نام فقط برای جست‌وجوی صفحه از نرمال‌سازی استفاده می‌کند.
- صفحهٔ شاعر از داده‌های بارگذاری‌شده تغذیه می‌شود و پس از تکمیل بارگذاری آرشیو، فهرست آن به‌روزرسانی می‌شود.
- اگر اثری نام شاعر نداشته باشد، صفحهٔ شاعر برای آن ساخته نمی‌شود.
