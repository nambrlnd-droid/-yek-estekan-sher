# نتیجهٔ ممیزی مرحله‌های ۳ و ۴ — ۷ نوامبر ۲۰۲۶

## دامنه و روش

ورودی، فایل `stage2-nonreligious-candidates.jsonl` از Artifact مرحله‌های ۱ و ۲ است: **۵۷٬۲۱۶ نامزد**.

برای تطبیق با محتوای موجود، فایل‌های دادهٔ شاخهٔ توسعه اسکن شدند: `poems.js`، `poems-extra.js`، `poems-user-collection.js`، `poems-hasan-collection.js`، `telegram-poems.js`، `internet-poems.js`، سه بستهٔ جدید و `pinned.js`. در این فایل‌ها ۲٬۴۰۹ متن خام استخراج و پس از نرمال‌سازی، ۲٬۲۱۲ متن یکتای اثر به دست آمد. این عدد «شمار runtime مرورگر» نیست؛ بارگذار پویای گنجور نیز در آن نیست.

نرمال‌سازی شامل Unicode NFKC، یکسان‌سازی ی/ک عربی و فارسی، حذف اعراب و کشیده، حذف فاصله و نشانه‌گذاری و نگه‌داشتن حروف و اعداد است.

## مرحلهٔ ۳ — حذف تکرار و تشخیص موارد مشابه

| شاخص | تعداد |
|---|---:|
| نامزدهای ورودی | ۵۷٬۲۱۶ |
| تطبیق احتمالی با متن‌های موجود سایت | ۹۹ |
| تکرار دقیق درون مجموعهٔ نامزدها | ۲۳۴ |
| کل موارد کنارگذاشته‌شده از مجموعهٔ یکتا | ۳۳۳ |
| نامزدهای یکتای باقی‌مانده | **۵۶٬۸۸۳** |
| جفت‌های مشابهِ نزدیک برای بازبینی | ۱۸۸ |
| رکوردهای درگیر در موارد مشابهِ نزدیک | ۳۷۶ |

**توضیح روش و دقت:** تطبیق ۹۹ مورد با سایت بر پایهٔ اثرانگشت ۶۴بیتی و فیلتر Bloom روی ۲٬۲۱۲ متن نرمال‌شده انجام شد؛ احتمال مثبت کاذب نظری این فیلتر حدود (3.72\times10^{-6}) برای هر پرس‌وجو است. بنابراین این ۹۹ مورد «تطبیق اثرانگشتی با اطمینان بالا» هستند، نه مقایسهٔ مستقیم بایت‌به‌بایت متن. تکرارهای درون مجموعه با SHA-256 متن نرمال‌شده تشخیص داده شدند.

تشخیص نزدیک‌بودن، محافظه‌کارانه و با بلوک‌بندی بر اساس شاعر به‌علاوهٔ پیشوند متن یا عنوان انجام شد. ۱۸۸ جفت فقط برای بازبینی علامت خوردند و **از مجموعه حذف نشدند**. این جست‌وجو جامع نیست و مقایسهٔ نزدیکِ تمام نامزدها با تمام متن‌های سایت انجام نشده است.

- طبقهٔ سوم: زیرموضوع
- قالب شعری در فیلد جداگانهٔ `form` ثبت می‌شود؛ قالب، موضوع نیست.

## پرچم‌های بازبینی مرحلهٔ ۴

پرچم‌ها می‌توانند هم‌زمان روی یک رکورد وجود داشته باشند:

| مورد نیازمند بررسی | تعداد رکورد |
|---|---:|
| نیازمند بازبینی موضوعی | ۴۹٬۲۵۸ |
| نیازمند تکمیل پیوند مستقیم صفحهٔ اثر | ۵۶٬۸۸۳ |
| دارای واژگان حساس برای بازبینی احتمال محتوای مذهبی | ۶۰۷ |

وجود واژگان مذهبی به‌تنهایی به معنای مذهبی‌بودن اثر نیست؛ این ۶۰۷ مورد فقط برای بررسی انسانی علامت خورده‌اند. هیچ‌کدام خودکار به محتوای مذهبی یا غیرمذهبیِ تأییدشده تبدیل نشده‌اند.

## وضعیت حقوقی و انتشار

- همهٔ ۵۶٬۸۸۳ رکورد هنوز نامزد هستند؛ هیچ‌کدام برای انتشار تأیید نشده‌اند.
- در خروجی فعلی برای تمام نامزدهای یکتا، پیوند مستقیم صفحهٔ اختصاصی اثر باید تکمیل شود؛ نشانی عمومی مجموعه به‌تنهایی منبع قابل قبول برای هر شعر نیست.
- مجوز اعلام‌شده در کارت مجموعهٔ داده، تضمین‌کنندهٔ وضعیت حقوقی تک‌تک اشعار نیست. حقوق هر اثر و شرایط بازنشر باید جداگانه بررسی شود.
- ۶۰۷ رکورد دارای نشانهٔ واژگانی برای بازبینی احتمال مذهبی‌اند؛ با سیاست پروژه، هیچ اثر مذهبی جدیدی نباید وارد سایت شود.
- مرحلهٔ ۵ باید متن کامل، انتساب شاعر، پیوند مستقیم، موضوع، وضعیت مذهبی و حقوق را به‌صورت موردی بررسی کند.

## فایل‌های خروجی

خروجی قابل اشتراک در این گفت‌وگو به‌صورت بستهٔ فراداده‌ای `stage3-stage4-metadata.zip` تهیه شده است؛ متن کامل شعرها عمداً از آن حذف شده، چون وضعیت حقوق بازنشر تک‌تک آثار هنوز بررسی نشده است. این بسته Artifact رسمی GitHub Actions نیست.
